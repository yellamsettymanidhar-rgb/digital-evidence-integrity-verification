What happens on upload

  1. The file is validated (type and size).
  2. A SHA-256 hash is computed directly from the upload stream.
  3. The file is saved under a randomized filename to prevent collisions and path-traversal.
  4. An Evidence ID, the hash, and metadata are stored — this hash becomes the permanent reference point.
  5. A chain-of-custody entry ("Registered", "Uploaded") is created automatically.

Allowed file types

Images, PDF/Word/text documents, video, audio, and a few common archive/data formats. Executable and script files are not accepted.
